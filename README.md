# Dakar Opava

Moderní vícestránkový firemní web společnosti Dakar Opava, postavený na Next.js, TypeScriptu a App Routeru.

## Spuštění

```bash
pnpm install
pnpm dev
```

Produkční sestavení: `pnpm build`.

## Formulář

Poptávkový formulář nyní provádí validaci a bezpečně simuluje přijetí požadavku v prohlížeči. E-mail se zatím neposílá. Pro ostrý provoz připojte e-mailovou službu v route handleru a nastavte její klíč výhradně jako proměnnou prostředí.
